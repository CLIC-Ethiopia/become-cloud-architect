Infrastructure as Code

IaC Masterclass

From Native Frameworks to Agnostic Platforms, and strategies for avoiding critical operational pitfalls.

Native Frameworks

  • AWS CloudFormation

    YAML/JSON declarative stacks. Utilize StackSets for multi-account, cross-region deployments.

  • Azure Bicep

    Domain-specific language (DSL) abstracting ARM (Resource Manager) templates for cleaner syntax.

  • GCP Deployment Manager

    Declarative resource creation using YAML, Python, or Jinja2 templates.

Agnostic Platforms

  • Terraform

    HashiCorp Configuration Language (HCL). Provider-based architecture with robust remote state management.

    resource "aws_s3_bucket" "b" {
      bucket = "my-tf-test-bucket"
      tags = { Environment = "Dev" }
    }
  • AWS CDK / Pulumi

    General-purpose programming (TypeScript, Python, Go) compiled down to native configs. Enables OO code reuse.

  • Ansible

    Lightweight, agentless task automation for hybrid/on-premises configuration management.

Critical Pitfalls & Remediation

ClickOps

Manual console changes bypass compliance, lack review, and lead to security vulnerabilities.

Remediation

Adopt OIDC for short-lived credentials. Enforce strict RBAC and zero-user direct console access.

Drift

Actual cloud state diverges from desired IaC state due to emergency "hot-fixes".

Remediation

Automated drift detection. Use apply or import workflows.

WET Code

Oversized state files degrade speed. Copy-pasting directories violates DRY.

Remediation

Use Modular Programming. Split resources into workspaces. Use Terragrunt.
